# 📝 ToDoList

A lightweight, modular iOS app built with UIKit and Core Data. Designed for fast note-taking, offline persistence, and smooth UX.

## 🚀 Features

- Add, edit, delete notes
- Local storage with Core Data
- Remote sync with mock API
- Search and filter notes
- Context menu actions (edit, share, delete)
- Combine-powered reactive updates
- Modular architecture with test coverage

## 📦 Tech Stack

- Swift + UIKit
- Core Data
- Combine
- MVVM + Protocol-Oriented Design
- XCTest for unit testing

## 🧪 Tests

Includes unit tests for:
- CoreDataManager
- StartVM
- DetailsVC
- Search and deletion logic

## 🛠 Setup

1. Clone the repo  
   `git clone https://github.com/Teyitbek/ToDoList.git`

2. Open `ToDoList.xcodeproj` in Xcode

3. Run on Simulator or Device
